# mibib结构
`mibib.bin`文件大小为`512k`(`0x80000`)，其中共有两个备份，每个备份有两个副本  

第一个备份位于`0x0`：  
```
AC 9F 56 FE 7A 12 7F CD 04 00 00 00 00 00 00 00
```
前8个字节为`Magic Number`，后四个字节为`MIBIB Version`，这里是小端序，为`0x4`  
再往后4个字节是`age`，设为`0`即可  

第一个副本位于`0x800`，每个副本长`0x390`
```
AA 73 EE 55 DB BD 5E E3 04 00 00 00 10 00 00 00
```
|位置|内容|
|---|---|
|`8`字节|`Magic Number`，貌似是固定的`AA 73 EE 55 DB BD 5E E3`|
|`4`字节|`MIBIB Version`，设为`0x4`即可|
|`4`字节|分区个数，这里是`16`(`0x10`)  |

之后每`28`个字节描述一个分区  

|位置|内容|
|---|---|
|`16`字节|分区名字，注意加`\0`|
|`4`字节|起始地址，以块为单位，例如`0x4`有`0x80000`个字节（`0x4*0x20000`）|
|`4`字节|大小，以块为单位，同上|
|`4`字节|`attr`，好像是描述可读性的，设为`0xffff0000`即可|

接着填`0`  

第二个副本类似，起始于`0x1000`  
`Magic Number`变为`9A 1B 7D AA BC 48 7D 1F`  
每个分区的定义改变  
|位置|内容|
|---|---|
|`16`字节|分区名字|
|`4`字节|`A`数，详情见下|
|`4`字节|`B`数，详情见下|
|`4`字节|`attr`，变为`0xffff00ff`|
```
每个分区的大小（以字节为单位）= A * 400 + B*400
```
大小比较大时，`B`=`0x100`  
其余不知道  

校验值位于`0x1800`  
```
A1 BE 41 9D EA D2 DE F1 01 00 00 00 E9 22 55 B4
```
|位置|内容|
|---|---|
|`8`字节|`Magic Number`，貌似是固定的`A1 BE 41 9D EA D2 DE F1`|
|`4`字节|不知道，设为`0x1`即可|
|`4`字节|`CRC32`校验，多项式设置为`4C11DB7`，范围是从开头（`0x0`）一直到这个校验值前一行|
